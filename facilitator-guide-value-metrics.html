“How do we know we're delivering value, not just output?”

Velocity and on-time delivery say little about whether customers are better off. This board is based on Scrum.org's Evidence-Based Management (EBM), which looks at value through four key value areas: current value delivered today, unrealised value still on the table, time to market, and the ability to innovate. Each is tied to a strategic, intermediate and immediate goal, and the board ends with small experiments to improve the weakest area. It works for a product, a portfolio or a whole organisation.

1Before the session

  • Print the board at A3 or 11×17 (Tabloid), or larger, or load the SVG as a digital background
  • Bring whatever data exists: customer satisfaction, usage, cycle time, releases, defects, time on new work
  • Agree the scope: one product, a group of products, or the organisation
  • Invite people who can act on the results, not just report them
  • Bring the product vision, OKRs or strategy so goals line up

3The four key value areas

Each looks at value from a different angle; balance all four.

Current Value

  • Value customers get today
  • Satisfaction, usage, revenue
  • Employee satisfaction too

Unrealised Value

  • Value we could still create
  • Unmet needs, market gaps

Time to Market

  • How fast we deliver and learn
  • Lead time, release frequency

Ability to Innovate

  • What slows new value
  • Tech debt, defects, time on new work

Goals

  • Strategic, intermediate, tactical
  • Measures link to them

4Facilitation tips

Balance the fourOptimising one area, often time to market, can hurt another. Look at all four together.
Few measuresOne to three per area is enough. More measures mean less attention.
Trends over targetsThe direction over several reviews matters more than any single number.
Experiments, not mandatesTreat improvements as hypotheses: measure, then keep, adapt or drop them.
Leaders own itThe board is for decisions about investment and priorities, not for judging teams.
Start with what you haveImperfect data now beats perfect data never. Improve the measures as you go.
Common pitfalls: measuring only output; turning measures into team targets; too many measures; no baseline; reviewing numbers without acting; using it to compare teams.

5After the session

Straight away

Share the board with the teams and stakeholders affected.

This month

Start the experiments and set up the data you're missing.

Each review

Update the measures, look at trends, and decide what to keep or change.

Quarterly

Revisit the goals, and feed insights into OKRs and the Prioritisation Board.

6How it fits the toolkit

Value metrics sit above the rest of the toolkit: use them with OKRs to set direction, the Prioritisation Board to decide what to fund, and the flow pack (for example Ageing WIP) to improve time to market. The Outcome Status Report is a good place to share them.
