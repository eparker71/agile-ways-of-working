Make It Yours

Every board, guide and page here can be copied and changed to fit your teams. Pick the route that matches what you want to change and the tools you're comfortable with.

Route 1 · No editing

Print it, or put it on a whiteboard

  • Print: open any board's page and print at A3 landscape (larger is better for teams). Guides print at A4 portrait.
  • Digital whiteboard: download the board's SVG and add it to Miro, Mural or FigJam, then lock it as a background and add stickies on top. Most whiteboard tools import an SVG as a flat image, so you can't edit its labels there. Use Route 2 for that.
Route 2 · Change a board's wording or colours

Edit the SVG in a design tool

The SVGs hold real, editable text, not pictures of text. Open one in:

FigmaDrag the SVG onto the canvas. Double-click text to edit; select shapes to recolour.
Inkscape (free)File → Open. Use the text tool to edit labels; Object → Fill and Stroke for colours.
Adobe Illustrator or Affinity DesignerOpen the SVG directly; everything is grouped by panel.
A text editorFor quick wording changes, open the .svg and edit the text between <text> tags.

Install the fonts first so the text looks right. All are free from Google Fonts: Instrument Serif, Geist and Geist Mono. The worked examples also use Caveat for the handwriting. Without them, your design tool will use other fonts.

Keep the small credit line at the bottom left of each board, and add a note saying what you changed.

Route 3 · Change a guide

Download the Word version

Every facilitator guide has a Word (editable) ↓ link next to its board links. The .docx file has the same content as the web page: run-sheet tables, prompts, tips and follow-up. Change the timings, prompts or examples to suit your sessions, in Word, Google Docs or LibreOffice. The Marginal Gains guide is the one exception: it's only available as a web page.

Route 4 · Change everything, consistently

Copy the repository and regenerate

Most files are generated by Python scripts in _generator/ (standard library only, no installs needed). That makes it easy to rebrand everything or rewrite many tools at once.

  1. On GitHub, click Use this template to make your own copy. Or download the ZIP.
  2. Rebrand in one place: edit _generator/brand.py to change the accent colour, header colour and fonts.
  3. Change content where it lives:
    • _generator/build_boards.py: boards and worked examples
    • _generator/build_guides.py: facilitator guides and their Word files
    • _generator/build_roles.py: the tool list and the role page
    • _generator/build_glossary.py and build_antipatterns.py: glossary and anti-patterns
    • _content/scenarios.md and _content/recipes.md: the Scenario Playbook and Workshop Recipes, in plain Markdown
  4. Regenerate everything, in the right order, then check for broken links and other problems:
    python3 _generator/build_all.py
    python3 _generator/check_site.py
  5. Publish your own site: in your copy's GitHub settings, open Pages and deploy from the main branch, root folder. Your copy includes the automated checks, which run on every push. Set PUBLISH_AT in brand.py to your site's address, so link previews and the sitemap point to your copy. Leave the credit line as it is.

A few pages are hand-written and don't read brand.py: the home page, the two cheat sheets, and the Marginal Gains board and guide. Edit those directly. The README lists the details.

Before you share your version

A quick checklist

  • Keep the credit line, and say what you changed.
  • Make it clear your version is yours, and not endorsed by the original author.
  • Keep the credits to the people whose ideas a tool is based on, and any trademark notices.
  • If you improve something, consider sharing it back as an issue or pull request on GitHub.
